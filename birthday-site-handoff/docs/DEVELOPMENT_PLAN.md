# Codex 分阶段开发计划：A · 走进秘密花园

## 使用方式

将本交付包放入项目目录，让 Codex 先读 README.md 与 CODEX_PROMPT.txt，再按 M0—M5 分轮执行。本文文件名均相对交付包根目录；应用文件写入实际项目，不写进这份文档包。已有工程沿用原有结构，空项目再初始化。

当前目标是明亮、柔软、可探索的生日礼物花园：桌面上你们一起走近三个地方，之后对方可用手机直接回来抽曲子。保留 0305 谜题、九首固定曲目随机抽取与礼物揭晓。

本包是计划和配置，尚无应用代码、美术成品或网站运行结果。下文验收均指后续开发应实际执行的检查。

## 里程碑总览

| 阶段 | 核心产出 | 完成判断 |
| --- | --- | --- |
| M0 | 工程检查、配置、参考与素材清单 | 能启动；已有/缺少素材明确；没有假路径 |
| M1 | 可亲手操作的美术样片 | 总览好看，停着有呼吸，碰花有回应，靠近/返回自然 |
| M2 | 信号花圃与密码卡 | 从空答案实际解出0305，提示与刷新恢复可用 |
| M3 | 九首曲子的音乐花圃 | 随机、卡片、复制、重复抽取与直接回访可用 |

**第一轮先完成 M0 + M1。** 拿到能点击的画面后围绕构图与运动反馈；M1 尚未达成时优先修整画面、素材和相机，不继续堆叠业务页面。

九首最终曲目和礼物照片可以稍后提供，不阻碍 M1。美术素材不足可以先搭结构，同时明确哪些层仍需替换；几何占位不能被当作最终美术通过。

## M0 · 工程检查与素材整理

### 工作内容

1. 读取当前项目约定、依赖、lockfile 和交付包，判断是否已有可用工程。
2. 空项目采用 React + TypeScript + Vite；R3F/Three.js 承载有限分层舞台，GSAP 统一转场，HTML/CSS 呈现文字与输入。已有工程按实际情况整合。
3. 建立本地素材目录与状态清单：已存在、待制作、待用户提供、可省略。
4. 用户截图/视频放在开发参考位置，不放进正式发布内容。按 ASSET_BRIEF.md 提炼材质、配色与图层。
5. 接入 content.template.json，完成基础配置校验。不存在的素材路径保持 null；未知私人内容明确占位。
6. 实际启动项目并检查构建命令，记录安装版本与依赖。

### 产出与验收

- 可运行的工程骨架和统一内容配置入口；
- 素材清单及待补内容清单；
- 实际启动命令、构建命令与依赖版本；
- 没有重复初始化工程、虚构文件路径或私人经历。

### 给 Codex 的本轮指令

~~~text
先完成 M0。读取当前项目约定和生日花园交付包，保留已有工程；空项目再初始化 React/TypeScript/Vite，选择相互兼容的依赖。整理参考文件、素材清单，接入 content.template.json，区分已有素材、null引用和待补内容。实际启动并验证构建命令，不伪造资源路径或测试结果。完成后继续 M1。
~~~

## M1 · 可操作的美术样片

### 工作内容

只完成一个可以反复操作的短体验：看到花园 → 触碰一朵花 → 点击地标靠近 → 返回总览。

- 总览包含近处花叶、中间草丘/小路/地标、远处天空与云。
- 信号花圃、音乐花圃、礼物门先有可识别轮廓与位置。
- 鲜活苔藓绿为主体，搭配天空蓝、花瓣粉、奶油白和少量暖光。
- 植物受同一阵风影响，云移动更慢，画面保留稳定重心。
- 鼠标移动产生小幅视差；触碰一朵花有柔和而明确的回应。
- 点击一个地标，视角靠近并出现真实 DOM 纸签与返回入口。
- 键盘、触摸可以完成同一操作；减少动效时关闭大范围相机运动。
- 资源或图形加载失败时，有同风格静态替代和可操作入口。

这一轮暂不实现整套 XOR、随机抽歌与密码锁。美术不是最后才补的装饰：先按照 ASSET_BRIEF.md 制作/接入完整总览及至少一个独立物件。

分层插画平面、轻量几何体与少量3D物件可以组合。若使用生成图像，背景/透明资产不包含界面文字；标题、数字、按钮和交互由代码实现。概念图用于定美术，实际页面需要可响应的独立层。

### 审阅产出

- 本地可操作样片；
- 桌面总览和近景的实际截图，建议约1440×900；
- 小屏截图，建议约390px宽；
- 工具允许时提供约20—30秒操作录屏：打开、触碰、靠近、返回；
- 已完成素材、剩余占位与当前限制。

这些尺寸和时长用于审阅材料，不是页面强制播放时长。不要为录屏效果加入自动推进。

### 本阶段验收

- 不操作时仍是一幅完整、有层次的花园画面；
- 柔软、手作、鲜活的方向与用户参考一致；
- 环境有共同节奏，文字与输入区稳定；
- 入口可发现，靠近和返回不跳位；
- 连续做三次进入/返回，不叠加相机或时间线；
- 触摸、键盘与减少动效模式均可完成；
- 普通球体、平铺色块、三张卡片尚未替换时，只能说明结构完成。

### 给 Codex 的本轮指令

~~~text
完成 M1 可操作美术样片，只做漂亮的花园总览、近中远图层、温和环境运动、一朵花的触碰反馈、一次地标靠近与返回。严格参考 DESIGN_AND_ACCEPTANCE.md 和 ASSET_BRIEF.md，不把几何占位或极简卡片当最终视觉。文字与按钮使用真实DOM；键盘、触摸和减少动效可用；相机由统一控制器管理。请实际运行并交付总览/近景/小屏截图、已验证行为及待替换素材。本轮做到样片即可，先不扩写三关业务。
~~~

## M2 · 完整信号花圃与密码卡

### 工作内容

1. 统一 overview/puzzle/music/lock/gift 五个视图及总览地标。首屏邀请属于 overview；bridge 只是一段谜题后过场。
2. 解码片1001，信号A=1010、B=1100。输出四位全部从null开始。
3. 先逐位 XOR 验证，再进入十进制输入：A得到0011→03，B得到0101→05。
4. 两张完成后按顺序得到0305密码卡，保留前导0。
5. 实现分级提示、主动辅助完成和业务进度保存；错误时保留填写内容。
6. 可继续1001→9过场，进入音乐花圃；也可返回总览。
7. “我的密码卡”仅在puzzleSolved成立时出现。生日含义此时不解释。

沿用M1确定的美术与空间，不让近景突然变成另一套后台表单。

### 产出与验收

- 能从空答案独立解出0305；初始null不被当作0；
- 3/03、5/05都接受；错误反馈温和；
- 只完成一张卡不能获得密码卡；辅助完成写入完整一致数据；
- 刷新可继续；存储失败时当次仍可完成；
- 首屏、素材替代文字、提示与结果没有提前揭晓生日含义。

### 给 Codex 的本轮指令

~~~text
在M1场景上完成M2：五态导航与完整XOR谜题。按TECHNICAL_SPEC.md处理null bit、bits→decimal→solved、两位格式化、密码卡、提示和恢复。1001→9仅作短过场。导航view、相机和动画phase留内存，不保存半途动画。为计算与状态条件写少量确定性测试，再在浏览器实际解一遍。保持已经确定的美术，不提前解释0305的生日含义。
~~~

## M3 · 九首曲子的音乐花圃

### 工作内容

1. 固定曲目ID 1—9与九朵音乐花，不因抽取改变映射。
2. 使用清楚的抽取动作；触碰单独花朵只作视觉回应。
3. 有效点击时同步防连点，先确定并保存lastDraw，再让种子/光点飘向选中的花。
4. 展开曲目卡、邀请文字、复制、再次抽取与返回。
5. 允许连续同一首，不做不重复队列、兑换扣减、每日限制或日期条件。
6. #music和总览点歌入口始终可直达，新设备不要求解谜。
7. 复制失败时显示可选择文字，页面不写“已发送”。

### 产出与验收

- 随机边界测试可得到1和9，连续相同结果合法；
- 快速连点只生成一次有效抽取；
- 动画期间刷新恢复已确定结果；刷新、复制和返回不重抽；
- 减少动效也显示同一个预先确定的结果；
- 新设备抽歌不会设置puzzleSolved或giftUnlocked；
- 曲目卡在电脑和手机都可读且方便截图。

### 给 Codex 的本轮指令

~~~text
完成M3。固定1—9曲目映射，每次独立等权有放回，允许连续重复。有效点击时同步防连点，先确定并保存结果，再播放视觉反馈；刷新/切页不能重抽。实现复制与失败后的手动复制，#music随时可进入且不改谜题/礼物状态。测试随机边界、重复和恢复，不做大样本频率测试。浏览器实际检查抽取、刷新和复制。
~~~

## M4 · 礼物门与真实内容接入

### 工作内容

1. 把远处已经可见的门接为lock近景，用文本输入保留0305的前导0。
2. 正确后先置giftUnlocked，再打开门呈现gift。
3. 新设备知道密码即可打开，但不伪造puzzleSolved和密码卡。
4. 在gift首次解释生日含义，展示真实礼物和现场交付文字。
5. 没有抽过曲子也能前往礼物门，已解锁者可以回来重看。
6. 替换称呼、九首曲名、可选选择理由、礼物名称/照片/文字。
7. 用户提供语音/短音效时再接入主动播放；没有音频也能完成。

### 产出与验收

- 0305成功，305与错误四位失败；
- 未解锁#gift转lock；
- 新设备正确密码只解锁礼物；
- 真实内容来自用户，未填项明确列出；
- 礼物图片缺失不破版，日期含义只在揭晓后出现；
- 结尾留出现场把实物交给对方的停顿。

### 给 Codex 的本轮指令

~~~text
完成M4礼物门与真实内容。密码保留字符串0305；giftUnlocked独立于puzzleSolved；新设备正确密码不能生成解题完成或密码卡。未解锁#gift转lock，不要求先抽曲子。生日含义仅在gift首次出现。将我提供的称呼、曲目、礼物接入统一配置；没有的继续明确占位，不编造回忆。语音仅在提供素材且用户主动点击时播放。
~~~

## M5 · 现场彩排、手机与交付

### 工作内容

- 用实际展示电脑与目标浏览器走首次完整体验；
- 实际手机检查点歌直达、输入、卡片、复制、开锁与返回；
- 检查刷新、快速点击、浏览器前进/后退和减少动效；
- 复制被拒绝、存储不可用、GL失败、关键素材缺失时都有可继续的路径；
- 实测加载与运动表现，再调整纹理、图层、DPR和阴影；不预先宣称60fps；
- 执行生产构建，整理README、内容替换、专用进度重置与部署指引；
- 全部素材本地化，在展示电脑启动静态预览服务，断开外网完整演练；
- 准备部署产物与说明，不自动发布、开付费服务或修改访问权限。

本地预览是现场备用，不等于线上站点支持离线PWA。首版不必引入Service Worker。

### 最终验收路径

| 路径 | 观察结果 |
| --- | --- |
| 首次现场 | 画面能等你们聊天，人主动继续，音频不突然覆盖讲话 |
| 完整解谜 | 从空bit到0305；提示不惩罚；获得后能查看密码卡 |
| 音乐回访 | 新设备直达；可重复抽同一首；刷新恢复最近结果 |
| 礼物直达 | 正确密码可开；不伪造解题；未解锁URL不能直接呈现 |
| 手机 | 关键入口可见；输入不被键盘/布局遮住；卡片可读可复制 |
| 降级 | 复制/存储/图形失败均可继续 |
| 现场备用 | 无外网、但本地服务运行时，全部所需素材与内容可用 |

### 给 Codex 的本轮指令

~~~text
执行M5交付检查。按最终路径，在可用浏览器验证首次体验、音乐回访、新设备已知密码、刷新、复制/存储失败、减少动效及小屏。检查图形和素材失败的静态替代与DOM功能。执行生产构建，给出实际结果、截图、未测设备和剩余问题。整理README、全部本地素材、内容替换和断网彩排步骤，准备部署说明，不自动发布。未执行的检查不能写成通过。
~~~

## 给Codex反馈时，尽量描述具体变化

例如：“前景太少，增加靠近镜头的花叶，保持小路清楚。”“绿色太灰，改成鲜活苔藓绿，粉色集中在主角物件。”“相机推进太猛，缩短距离，阅读时完全稳定。”“每朵花像各自抖动，改成同一阵风、略有幅度差异。”“曲目卡太小，把文字放在稳定的DOM纸签上。”

每轮优先修正一个明确问题，保留已经满意的构图、颜色和交互。推进顺序是美术与空间成立，再让互动清楚、业务可靠、目标设备稳定。
