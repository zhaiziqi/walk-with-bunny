# A 方案：秘密花园美术资产清单

## 1. 目的与制作原则

本清单让 Codex 可以从一开始就制作可操作的美术样片。目标是风格统一、层次清楚的花园世界，关键资产在 M1 就参与画面。默认在 R3F / Three.js 的有限 2.5D 舞台中组合分层插画、透明物件和少量关键几何，用 GSAP 管理短转场，HTML/CSS 保持真实可读的控件。无需先完整建模，也无需先学习 Blender。

生成图片适合概念图、场景层与独立装饰物件。**数字、谜面、输入框、按钮、曲名、私人文案都由网页实时渲染。** 把全部按钮画在一张图片上，不能形成可交付的网页。

本包提供资产规格与创作提示，不包含制作完成的花园图片、模型或音频。用户参考截图与视频用于审美对齐；其中的社交平台界面、通知和个人信息不进入网站资产。没有确认可使用的原文件时，不直接裁切原站主要美术作为成品。

## 2. 共同美术说明

明亮柔软的秘密花园，圆润的鲜活苔藓绿草丘，浅蓝天空、奶油白云朵、少量花瓣粉与淡紫花。近处花叶、中景曲折小路、远处低对比草丘形成层次。介于精致插画与柔软立体玩具之间，留有手作细节；左上柔光，阴影轻且方向一致。造型有机、主角轮廓清楚。

构图原则：

- 较近左中区域为信号花圃，中部沿小路为音乐花圃，偏右稍远处为奶油色小门；具体锚点由 M1 调整后固定。
- 标题与邀请放在干净天空或浅色空间，主角附近留可点击范围。
- 所有场景素材不包含文字、数字、标志、界面按钮、进度条与水印。
- 场景明亮；不加入夜间温室、厚重古典建筑、科幻终端和满屏发光粒子。
- 交互主体与背景分开，方便独立动画与竖屏重排。

| `sky-desktop` | 天空、低对比远丘、标题留空 | 2400×1500 | 否 | 最远层，小幅视差 | 初期可简画；M1 需有完整画面品质 |

## 5. 文件组织与内容配置

建议资源放在 `public/assets/garden/`，分 `overview/`、`signal/`、`music/`、`gift/`、`audio/`；已有项目沿用原目录。素材通过资产清单读取，避免路径分散在组件中。

`content.template.json` 的 `assets` 是待准备资源的内容入口，允许 `null`。本文件中的细分资产 ID 是实现阶段的资源清单建议，不要求把所有细分路径填进用户内容模板。一个概览字段可以由实现清单映射到多个图层；缺失时不填虚构路径。

清单至少记录以下字段：

| 字段 | 用途 |
| --- | --- |
| `id` | 稳定资产标识 |
| `src` | 项目本地路径 |
| `width` / `height` | 源尺寸与比例 |
| `role` | 背景、装饰、互动外观或内容照片 |
| `layer` | 远景、中景、前景或近景物件 |
| `anchor` / `pivot` | 场景锚点与动画轴心 |
| `status` | `placeholder`、`draft` 或 `ready` |
| `sourceNote` | 自绘、生成、用户提供或确认可使用的来源 |

坐标、位移、缩放与动效参数集中配置，不写入图片。桌面和手机允许不同锚点，业务逻辑不变。正式资源随项目提供，关键展示不依赖不稳定的外站热链。

## 6. 可直接使用的美术创作提示

使用时附上用户风格参考和已经确认的总览概念。工具不可用时按同样要求绘制或准备资产，不创建虚构文件路径来假装完成。

### 总览概念

> 为一个私人生日礼物网站设计明亮梦幻的秘密花园总览。横向 16:10，前景为少量靠近镜头的粉色花与绿叶，中景为圆润柔软、细微苔藓质感的鲜活绿色草丘和弯曲小路，远景为浅蓝天空、奶油白云和低对比远丘。左中靠近处是一小组透明灯，中部远一点是一片音乐花，右侧稍远是一扇奶油白小门，附近有花瓣粉的柔软缎带形植物。融合精致插画与软质立体玩具气息，轻盈、有手作细节、左上柔光。保留干净标题空间，主角轮廓清楚、颜色统一。没有人物、文字、数字、按钮、界面框、网页截图、水印和标志。这是美术概念，不是完整网页成品。

### 中景环境层

> 参照已确认的花园概念，生成同一视角、同一光线的草丘与弯曲小路中景层。保留柔软鲜活的苔藓绿与圆润形状，左中、中部、右侧三处目的地留空。独立透明背景，无天空、前景花叶、灯、音乐花、小门、文字与数字。上下边缘充分延伸，方便视差和裁切；透明轮廓边缘干净。

### 前景花叶

> 参照已确认的花园色彩与材质，制作左下近景的一簇花叶，独立透明背景。轮廓柔软有机，粉色花朵与苔藓绿叶片，轻微手绘细节和柔和体积光。花枝根部收在左下，向上向内伸展但不占中心。无文字、数字、标志和背景场景，花叶边缘完整，适合分层摆动。

### 音乐花

> 制作同一秘密花园里的一朵独立音乐花，透明背景，左上柔光。花瓣粉与奶油白，柔软圆润，形状略带想象力，介于精致插画和软质玩具之间。根部位于画面下方中点，轮廓完整，花心简单清楚。无文字、数字、音符符号和按钮。适合轻微摆动与选中时展开；后续变体保持相同视角和质感。

### 礼物小门

> 制作同一秘密花园里的奶油色小门，独立透明背景，轻巧圆润、有手作气息。少量花瓣粉缎带状植物与叶片围在门边，左上柔光，正面带温和透视。门扇和门框边界清楚，方便拆层开门。无密码、数字、文字、图标、门牌和背景建筑；没有厚重石门、金属锁或夜景。

每类资产都放回同一场景检查。单张图漂亮但透视、光向或比例不匹配时，应调整资产或构图，不用粒子和模糊遮掩。

## 7. 退化与缺失处理

图形不可用时，使用静态分层图片与 DOM 控件完成同一流程。减少动态效果时关闭风、视差与长位移，保留完整构图。资源缺失时装饰可隐藏，关键地标保留清楚的替代入口；不要让图片加载结果决定密码验证或随机结果。

阶段交付需要区分：

- **结构完成：**入口、位置与状态已接通，仍有未完成的视觉资产。
- **视觉完成：**主画面与主要物件达到统一的拟定风格，已做桌面和竖屏检查。
- **正式内容完成：**九首曲子、真实礼物和私人文字已替换。

这三个状态不能互相代替。照片、语音和曲目可以后补，不阻塞舞台、谜题和随机逻辑实现。

## 8. 素材验收

- 同屏物件的颜色、光向、透视和清晰度协调。
- 透明边缘无白框、残底、明显锯齿或截断；实际显示不严重超出源分辨率。
- 数字与文字是实时内容，更改配置后可以同步更新。
- 页面只加载实际使用的生产素材，工作大图与未用变体不成为首屏依赖。
- 装饰资源失败可隐藏；礼物图片失败仍能阅读礼物文字。
- 交付列明每个 `placeholder` 与 `draft`，说明替换后需检查的构图。
- 主要控件可准确点击和用键盘操作，装饰纹理不遮挡操作区。
