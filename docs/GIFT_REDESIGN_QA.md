## 原因与调整

主预览已有 giftUnlocked=true。旧 App.openPlace 会在访问小门或礼物快捷入口时直接展示已解锁内容；未解锁来源的 #gift 路由本来会转到 #lock。此次没有发现从空进度跳过密码校验的路径，也没有清空用户存档。

所有正常礼物入口现在先进入包裹页。未解锁时输入四位密码；已解锁时明确显示 You opened this gift earlier，并提供 Open again 与 Try the code again。后者只改变面板局部显示状态，仍经过真实密码校验与原解锁流程，错误码不能利用已有解锁记录直接展示礼物。关闭或刷新可回到正常已开状态，不会撤销既有成果。已解锁者直接访问 #gift 仍能回看；这是有意保留的行为。

揭晓页去除编号商品卡、A small signature 折叠说明及宽大实心按钮。两件礼物以一张原创水粉静物呈现，共置于展开薄纸上；保留生日标题、简短礼物名称和轻量返回入口。内容面板改为不透明纸色，避免身后的门与角色透进阅读内容。保留清楚的键盘焦点样式。锁页信封及四位密码输入仍可用。

插画为物件类型示意，并非实物照片。内置 ImageGen 生成的1536×1024 RGBA原图保存在 `public/art/floof/gift-keepsakes-painting-v2.png`，未修改透明通道。精确提示、源文件与SHA见 [生成记录](research/2026-11-02/gift-keepsakes-v2.md)。现有SVG仅作图片失败时备用显示。四题、0305、九首曲目、礼物名称及content.json全部未变。
