# Garden typography

The English interface uses **Cormorant Garamond** for narrative text and a system sans-serif for controls. This is a licensed alternative chosen for a light, literary feel; it is not claimed to be the exact typeface used by Wayfinder.

- Official family source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Author/project: https://github.com/CatharsisFonts/Cormorant
- Full unmodified upstream variable TTF retained here as `cormorant-garamond-variable.ttf`.
- Runtime Latin WOFF2: `/public/assets/fonts/cormorant-garamond-latin.woff2`, downloaded from the Google Fonts CSS API on 2026-11-01.
- Runtime source: https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtKky2F7g.woff2
- License: `/public/assets/fonts/OFL-CormorantGaramond.txt` (SIL Open Font License 1.1).

The font is served locally and preloaded. No external font request is made by the page. Weights 300–500 are available; titles use 300, narrative text uses 400.
