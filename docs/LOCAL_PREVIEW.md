# 本地桌面预览与现场备用

适用当前生日花园工程。手机继续暂缓；这些步骤不部署网站，也不建立离线 PWA。九首曲名及护照夹、睡眠眼罩两件礼物名称已确认并接入；可选的真实礼物照片、选择理由、收礼人称呼、送礼人署名和私人演奏音频尚未提供，不影响当前体验。礼物采用原创水粉插画，名称藏在可翻看的小兔纸签后；音乐花圃提供抽取和复制点歌请求，没有真实曲目播放器。当前第一关使用四道计算机知识题和纸条／信封流程，完整规格保存在开发工程的 `docs/FOUR_QUESTION_PUZZLE.md`。

## 本轮从头体验的生产预览

用户预览固定使用 **http://127.0.0.1:4197/#garden**，生产包来自 `releases/desktop-preview/dist/`，不带 `Preview only` 或诊断控件。该来源与开发地址 `localhost:5173`、本轮检查地址 `127.0.0.1:4196` 相互隔离。首次打开无既有进度；之后刷新和重开仍续用这个地址自己的进度，不会每次清空。原开发存档不被读取、改写或重置。

需要重开本轮预览时，在工程根目录执行：

```sh
sh scripts/project.sh preview --port 4197 --root releases/desktop-preview/dist
```

也可双击备用包内的 `START_GARDEN.command`，随后在浏览器打开上面的地址。脚本查找本机已安装的 Node（包括本机 Codex 运行时与常见 macOS 安装位置），不会下载安装。服务已经运行时直接打开链接即可；重复启动会报告端口占用。停止服务不会删除浏览器保存的进度。

`4196` 用于本轮独立验收，不是给用户的空进度入口。检查记录见开发工程的 `docs/DESKTOP_RELEASE_QA.md`；不要把在验收地址完成的流程误认为用户预览已被玩过。

## 日常开发

在项目根目录运行：

```sh
sh scripts/project.sh dev
```

打开 `http://localhost:5173/`，保持终端运行。5173 已被现有服务使用时复用它；需要另开测试服务时必须指定另一个端口，例如：

```sh
sh scripts/project.sh dev --port 5175 --strictPort
```

`project.sh` 优先使用系统 Node；本机没有常规 Node 或命中了 `cua_node` 时使用 Codex 的 Node 运行时。其他电脑建议安装 Node 22.12+ 或 24。已有依赖可离线启动，首次安装依赖仍需要预先完成。

## 构建后的现场预览

```sh
sh scripts/project.sh build
sh scripts/project.sh preview
```

默认打开 `http://127.0.0.1:4173/`。预览读取 `dist/`，修改源文件后需重新构建。按 Ctrl+C 停止服务；不要直接双击 `dist/index.html`。

生产预览使用 `scripts/serve-dist.mjs`，只依赖 Node 标准库，固定监听回环地址。它不请求或代理外网，不访问父目录；未知资源返回 404，不用 HTML 冒充缺失的图片、字体或脚本。默认端口被占用会明确失败，不会悄悄换端口。

需要指定端口或已构建目录时：

```sh
sh scripts/project.sh preview --port 4181
sh scripts/project.sh preview --port 4181 --root /absolute/path/to/dist
```

只有 `preview` 接受 `--root`；不指定时，目录始终相对服务器脚本定位，和打开终端的位置无关。`dev`、`check` 参数分别传给 Vite／TypeScript；`build` 先检查类型，再把额外参数传给 Vite build。未知参数会由对应工具报错，不会被忽略。

## 没有 node_modules 的备用包

备用包保持下面的相对结构即可独立运行：

```text
birthday-garden-preview/
  START_GARDEN.command
  START_HERE.txt
  dist/
    index.html
    assets/…
    art/…
    fonts/…
  scripts/
    serve-dist.mjs
```

在已有 Node 的电脑上，运行：

```sh
node /absolute/path/to/birthday-garden-preview/scripts/serve-dist.mjs
```

也可明确加 `--port 4181`。这一步不需要 pnpm、Vite、npm 下载或 `node_modules`。脚本会从自身位置找到旁边的 `dist`；携带完整目录，不能只复制 `index.html`。备用包不需要包含开发参考、原始图片、聊天导出、源码备份或用户私人文件。

## 现场彩排顺序

1. 在展示电脑上预先启动本地服务、打开指定地址，确认图片、字体和文字加载完毕。
2. 固定使用同一个主机名与端口；`localhost` 与 `127.0.0.1`、5173 与 4173 都属于不同浏览器来源，各自保存进度。更换地址看不到原进度，不代表内容被删除。
3. 从花园开始，确认能自由停留；依次回答四题，观察纸条累积为 0305，主动收进信封并回看；随后点歌、输入密码开礼物，再关闭面板回到原位置。
4. 测试刷新、浏览器后退／前进、减少动态和不按原顺序直接点歌。音乐、谜题、礼物进度应互不混淆。
5. 要验证现场断外网备用，可在本地服务持续运行时由展示者断开外网，再重新加载并走完整流程。确认图片和字体仍在、没有等待远程文件。断网不应关闭本地 Node 服务。
6. 保留备用包与启动说明。音频默认关闭，真实语音尚未提供时不出现播放器。

上述是彩排步骤，不是所有设备已经通过的声明。实际做过的检查、截图、网络检查范围和未测事项以本轮 QA 记录为准；不能把“所有文件均为本地路径”直接等同于“已经实测断开物理网络”。

## 保留进度与独立首次体验

当前版本写入 `birthday-gift:0305:v2`，保存四题输入／正确数字、信封收存状态及独立的曲目／礼物状态。旧 `birthday-gift:0305:v1` 不再写入；首次没有 v2 时，只读旧键迁移礼物解锁和有效最近曲目。旧两组题完成不表示新四题完成，新题从第一题开始。原 v1 记录保留。

同一来源的新版标签页会同步进度，并保护已答对数字、信封和解锁成果。修改存储前先关闭该来源的其他花园标签，否则仍打开的页面可能恢复其内存中已获得的成果。旧开发标签请先刷新加载新版；不同主机名或端口之间仍不互相同步。多标签并发保存不是数据库事务，不保证多个页面同时写入后立即全部关闭的原子性。

要做完全空进度彩排，使用一个尚未保存本项目进度的独立端口，或另一个浏览器配置。既有 v1／v2 和其他网站数据均保留，不为制造空状态删除存档，不使用 `localStorage.clear()`。地址后添加 `#garden` 只是回到花园，并不重置进度；生产版本也不会启用开发用的 `?preview=fresh` 参数。

## 常见情况

- `ERR_CONNECTION_REFUSED`：本地服务没有运行，先按上面的命令启动；仅打开网址不会启动程序。
- 端口被占用：检查是不是之前的预览已在运行；复用它，或明确换一个端口，并注意该来源的进度可能为空。
- 找不到构建文件：先执行 build，或检查 `--root` 是否确实指向包含 `index.html` 的已构建目录。
- 存储不可用：当前访问仍可完成流程，但下次打开可能需要重新输入密码或重新抽曲。
- 图形不可用：使用 `?static#garden` 进入静态替代，例如 `http://127.0.0.1:4173/?static#garden`，DOM 谜题、音乐和礼物仍可使用。

正式上线属于后续单独工作。本地备用服务不会自动发布、生成公网链接或修改访问权限。
