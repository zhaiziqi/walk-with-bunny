# 石拱至山丘与礼物门 · 桌面检查记录

日期：2026-11-02。本轮范围为旧石拱之后的山丘 `(1000, 6800)`、连接弯道和礼物门 `(-200, 8500)`，以及由门前返回山丘。保留已有水粉草坡、奶白绒团、运动参数、英文界面与四题／九首曲目／0305 礼物规则。以下结果不代表本轮重新走通全部八个区域，也不代表全花园视觉已获最终验收。

## 本轮实现

山丘使用偏灰紫的局部底色，门前渐入冷蓝灰；两区及中间弯道的纹理局部柔化，原有三个植物群只调整位置。四只纸鸟停在不同落点，停留或主动回应后依次起飞，经过展开、抬升、转弯、回落，最终回到原来的落点。飞行中再次触发不会让鸟群突然回到起点，阅读期间冻结当前动作。

门前以一条窄而柔和的月光连接门槛，月盘位于门的侧后方，六个光点在各自附近漂移。替换原有规则圆环与绕圈光点，使主要视线落在小门和来路上。小门采用新的透明水粉素材，完整世界尺寸为 340×510；正常图片落脚点为 `1489/1536`，程序备用门为 `626/640`。尺寸、落脚点与 DOM 目标统一使用共享配置，门的位置和阅读焦点未移动。

WebGL 与静态画面共享鸟的驻留布局、月光、月盘、光点、门的尺寸和脚点，以及两区地面色温与纹理柔化范围。减少动态保留静止构图；正常渲染器恢复时消费旧事件与旧回应序号，避免因切换重新起飞。

## 礼物阅读与原位置返回

本机原有状态为 `giftUnlocked=true`。因此点击世界小门后直接进入 `#gift`，展示 Passport holder 与 Sleep mask；本轮实际浏览器没有重新输入 0305，也没有重置进度来制造一次解锁流程。未解锁、错误密码、前导零、保存顺序与动画取消等路径由内存隔离的确定性检查覆盖。

`gift-reading-settled` 与 `gift-reading-after-arrow` 的 `actorX`、`actorY`、`cameraX`、`cameraY`、`cameraZoom`、`headingX`、`headingY` 七项完全相同：阅读稳定后按方向键，没有带动角色或镜头。`gift-return` 与打开前的 `door-motion-restored` 七项也完全相同，随后完成原生按键返程。

全程保留原曲目编号 `2`、`drawId` `b34cc731-31fc-4f8c-999b-c42c87c3fef2:1`、未完成的四题与信封、已解锁礼物。此项证明已有状态保留，不是新的解谜／抽曲／开锁全流程。本次检查使用世界小门入口；顶部音乐／礼物快捷入口的关闭焦点行为未在本轮扩大修改。正常预览的浏览器日志没有 error／warn。
