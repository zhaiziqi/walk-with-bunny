# 水彩小兔花园 · 本轮检查

青柠检查通过（仅指下列实际执行的功能检查，不代表整体视觉已获用户验收）。

日期：2026-10-30。当前交付范围仍为 M0＋M1 可操作美术样片。用户认可的是 `quiet-garden` 水彩底景方向，并选择「明亮入口，探索后渐入暮色」。

## 页面与素材

- 本地服务：<http://localhost:5173/>，当前使用真实 WebGL 渲染。
- 保留大面积浅色天空、纸感与少量边缘花草；加入原创抱花兔子。花灯、粉花、小门采用同组柔和水彩素材，原交接文件与参考文件不变。
- 导览取景把物件脚下放在草坡区域。局部淡草地、接触阴影与少量草叶衔接根部；完整轮廓在边缘淡出，避免只露门顶或物件脚部。
- 背景是有界微视差绘画层，前景物件位于共享二维世界坐标。这是可自由平移的绘画场景，不是沿三维道路向前行走。拖到任意位置时，远景地形与前景不是一套可碰撞的三维地形。
- 界面仅在入口显示大标题；探索时只保留短提示、可展开导航和必要快捷入口。点击后出现稳定 HTML 面板。
- 植物共享缓慢风向，根部固定；远雾更慢。光线由位置决定，回到入口恢复明亮，不随时间自行变暗。
