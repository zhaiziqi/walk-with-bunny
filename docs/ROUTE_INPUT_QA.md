# 持续指向与主线衔接验收

日期：2026-11-03。桌面开发预览 `http://localhost:5173/`，运动版本 `point-to-walk-v1`。

## 行为与原因

用户最终确认：把指针放在某个方向后应持续行走，不需要手一直滑动。此前的 740ms 静止超时与“追到指针对应位置”两套行为都会使角色慢下或停下。

- `pointerGuidance.ts` 保留真实坐标变化、入口防误触和取消保护，取消静止超时。
- `pointToWalk.ts` 与 `useMeadowJourney.ts` 在真实指针移动时捕获方向／速度，静止时保持。停止区对齐当前绒团身体；进入停止区用 0.36 秒有限曲线收势。摄像机移动不重算持续方向。
- 按钮、阅读、地图、失焦、隐藏页、离开画面会清空输入；返回后需要新的真实指针移动。画面内边缘持续，真实世界边界与池塘不可穿越。
- `.header-actions` 空白间隙透传，真实按钮仍可操作并暂停。浏览器命中检查确认 gap 返回 `journey-surface`，容器 pointer-events 为 none，按钮为 auto。
- 触屏 hold 分支保留；本轮未做触屏实机验收。

## 主线衔接

未解完四题或未收信封 → 解题桌；已收信封且未抽曲 → 音乐花圃；已抽曲且未开礼物 → 礼物；已开礼物后不再提示下一站。只作引导，不增加关卡门槛或改写进度。

`mainRouteGuide.ts` 使用角色实际位置和既有路径，在 100 世界单位格变化时重算路线，避开池塘岸线；没有在每帧遍历整园。界面复用一句短提示和小箭头。地图标记下一站，未到访地区仍不可传送。礼物页沿用 Open my envelope，仅回看已解数字，不自动填码。
