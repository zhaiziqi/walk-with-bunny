# 连续探索 · 入口—小路—信号花圃

更新日期：2026-10-30（Asia/Shanghai）。本轮修正此前“纵向手势、横向长图移动”的实现，改为透视相机沿小路纵深前进。仍属于 M1 美术与交互改进，完整 XOR 谜题、随机抽歌和密码开门尚未接入。

## 体验路径

首次进入显示简短邀请。点「走进去看看」或开始拖动、滚轮后，首页大标题收起。向上拖动或向下滚轮推动镜头沿预设小路向纵深前进，反方向输入则后退；横向输入只提供有限探看，允许在任意位置停留。入口粉花与门位于路线近段，信号花灯位于远段。前进时近处物件变大、下移并从镜头两侧经过，远处花灯逐渐接近；途中地形、小路和苔藓边坡都保持固定世界落点。

点击完整可见的物件打开内容面板，场景旅行暂停。阅读区与按钮保持在稳定的 DOM 层，关闭面板回到刚才的位置。「我来点歌」可直接查看音乐花圃样片，关闭后恢复快捷入口使用前的路程。按「回到入口」或底部端点按钮会主动沿路导航。

键盘聚焦花园后，方向键调整路程/探看，Page Up / Page Down 较大步前后移动，Home / End 前往端点。底部位置条也可直接选择途中位置。面板支持关闭按钮、继续散步与 Escape，Tab 焦点限制在面板内。

## 场景与控制责任

| 文件 | 责任 |
| --- | --- |
| `src/scene/world.ts` | 三维物件坐标、草坡高度与小路中心线、物件尺寸/根部修正、路程到透视相机的映射、DOM 投影 |
| `src/scene/journey.ts` | 路程和有限横向值的纯输入数学，滚轮单位换算和边界 |
| `src/motion/useJourney.ts` | 原生指针、滚轮、键盘输入；路程状态；主动导航的 GSAP 插值 |
| `src/scene/GardenCanvas.tsx` | 透视相机、草坡网格与路面、固定物件与遮挡层、共同风场和独立薄云 |
| `src/scene/StaticGarden.tsx` | 使用同一透视投影的 SVG 地形与静态物件；动态关闭或图形失败时仍可探索 |
| `src/App.tsx` | 邀请、物件点击范围、轻面板、关闭后位置和焦点恢复、hash 导航 |

路程 `progress` 范围为 0—1；横向 `pan` 范围为 −1—1，实际世界位移有界。手势输入从按下时的原点计算，不依赖事件触发频率；松手即停，不保存速度。主动导航可以被新的输入打断。面板开启期间停止输入和导航插值，不让阅读时的滚动改变观察位置。

相机应用 `world.ts` 给出的三维位置、俯角与视角。当前路程把相机纵深 `z` 从 1050 移动到 −100，随路程略微降低高度；横向偏移独立且有界。草坡由 `groundHeight(x, z)` 定义，小路围绕 `roadCenter(z)` 延伸，路面半宽 64、路肩半宽 76。静态花园、WebGL 和可点击的 HTML 位置共享透视投影。原始透明物件底部留白通过 `footInset` 修正，根部、接触阴影和草叶沿物件的世界落点布置。

当前是预设路线中的透视纵深旅行：地形和路面为三维网格，花、灯、门和苔藓边坡为固定在三维空间中的透明图片造型，不提供自由转向或任意路线行走。`environment.webp` 作为固定天空与远丘，`ground-moss.webp` 铺在独立起伏草地网格上；小路另有生成的细砂纹理。远景里原有的云仍不独立移动，新增的 `cloud-wisp.svg` 缓慢漂移。静态替代使用 SVG 草坡与路面，不依赖横向长图平移。

此前 `journey-panorama.webp` 横向延伸版及其源图继续保留，当前仅可作为环境素材缺失时的远景备用。它不再定义探索路线，也不用于模拟向前行走。

## 美术与界面范围

保留原有粉花、花灯和奶油门。草坡网格与小路构成入口到信号空地的连续空间，透明苔藓边坡分布在路线两侧，后段向外让出花灯视线；花根/灯座配有局部阴影与草叶，门前保留踏石。新增苔藓地面源图为 `docs/art-source/ground-moss.png`，运行导出为 `public/assets/garden/ground-moss.webp`。素材详情与生成记录分别见 [ASSET_MANIFEST.md](ASSET_MANIFEST.md)、[ASSET_PROMPTS.md](ASSET_PROMPTS.md)。

浏览时没有大说明便签。点击后面板只保留标题、必要提示、操作、反馈和继续散步入口。现有信号面板仍是点灯演示，音乐面板仍是花朵回应，门仍是闭合样片；没有用假谜题、假抽歌或假解锁替代完整业务。

本轮未修改固定的 `0305`、XOR 数据、九首固定编号和有放回抽取规则，以及谜题与礼物解锁独立的状态契约。未填的真实曲名、礼物、称呼、照片、音频继续保持原状态。
