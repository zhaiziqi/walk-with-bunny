# M2 · 信号谜题检查

日期：2026-11-01。桌面优先，沿用 floof-clearing-v1 美术。本轮修改前源代码备份为 `versions/before-m2-20261101.tar.gz`；原始交接文档与 reference 未改。

## 完成内容

信号 A/B 从四个 null 空位开始，按 bits → decimal → solved 推进。正确灯位后才显示权重与数字输入；A 完成后才进入 B；错误保留填写，完成卡只读。数字输入接受 3/03 和 5/05，并保留两位结果。两组都完成才出现密码卡和顶部快捷入口。

提示分级：比较方法 → 一个位置与规则 → 主动完整示范。只有点击 `I understand · Keep this part` 才写入当前组完整一致的完成数据。可选 `1001 → 8 + 1 → 9` 连接音乐区；不提前解释密码的生日含义。音乐与礼物仍是后续阶段的预览。

业务进度使用 `birthday-gift:0305:v1`；恢复时校验输出、阶段、数字和片段，重新推导完成状态，不信任单独完成标志。存储访问、读取、写入均捕获失败；失败时继续内存体验。镜头、角色、提示展开、动画和路线发现不进入业务存储。

## 实际浏览器步骤

使用本机 Chromium/IAB DOM 操作与实际截图，桌面测试页为 1280×720。解题测试使用 `127.0.0.1:5173`，构建/辅助路线使用 `localhost:4173/?static`，与用户的 `localhost:5173` 存储隔离。用户预览保留未填写的第一关。

1. 空白 A 的八个 0/1 单选控件均未选中，`Check these lights` 禁用；初始页面没有权重、数字输入或密码卡。
2. 填入第一个 0 后刷新，仍只有第一个位置选中。填错为 0111 并检查：错误提示出现，四个选择保留。
3. 改为 0011 后进入数字阶段，灯位只读，权重8/4/2/1可见，输入框为空且获得焦点。输入4答错，保留4；刷新仍为数字阶段、值4。输入3通过，显示03检查点。
4. 点击下一组，B四个位置为空。逐级打开提示，到完整示范时仍未完成；返回自己的答案后没有自动填入。手动填0101、输入05，才显示完整0305卡。
5. 完成后刷新仍有密码卡；关闭出现 `My password card`。展开可选连接显示1001、8+1=9；切换音乐预览并关闭，仍返回原始角色与镜头位置。
6. 浏览器后退/前进正确经过音乐、谜题和总览。Escape关闭后焦点返回密码卡快捷入口。Shift+Tab/Tab在对话框首尾循环，不落到背景控件。
7. 减少动态模式中仍可打开密码卡。独立的生产构建静态模式中，从空A打开完整示范并明确确认，只完成A；B仍为空。返回入口出现 `Continue the signal`，点击和刷新均恢复到B。
8. 从入口点击继续后立即关闭，恢复原始位置、缩放和朝向；阅读时场景不接受移动输入。阶段切换重置面板滚动位置，普通填写不重置。最终生产构建实测切换数字阶段后scrollTop为0、焦点位于decimal-B；静态模式提示在阅读时收起，避免覆盖关闭按钮。
9. 测试页和新鲜预览的浏览器 error/warn 日志为空。本地5173服务返回HTTP 200，继续复用PID2450。
