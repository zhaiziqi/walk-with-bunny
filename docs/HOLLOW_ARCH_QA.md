# 池塘至蘑菇空地与旧石拱 · 桌面检查记录

日期：2026-11-02。范围为池塘之后的蘑菇空地 `(1400, 4300)` 与旧石拱 `(-1100, 5400)`，包括连接弯道、局部环境回应、静态替代及地图返回焦点。保留现有水粉草坡、奶白绒团、地形高度、运动参数和英文界面；四题、九首曲目抽取与 0305 礼物锁规则未改变。

## 本轮实现

蘑菇空地使用五株大小错落的灰粉色水粉蘑菇，给中央行走空间留白。根部固定在地形上，接触阴影留在地面；回应依次传递，表现为轻微倾斜、舒展和局部微光。没有将整株蘑菇上下移动来模拟生长。两区地面通过共享世界坐标场渐变：空地略偏灰紫，经过弯道逐渐过渡到旧石拱附近的冷蓝灰，局部减轻纸纹对比。已有植物仅调整位置和尺度。

石拱使用透明水粉素材，两个石脚适应现有坡度，上部拱形和风铃悬挂点保持稳定。风铃从上端轻摆，主动回应有连续起势和衰减；七个稀疏光点在各自的小范围漂移。此处的风铃回应指视觉摆动，本轮没有新增可听见的风铃音效。两区按距离连续显现和隐去，不因进出固定 Y 边界突然出现整组物件。

WebGL 与静态画面共享蘑菇位置、尺寸、落脚点、拱门贴地形变、色温场和光点驻留位置。减少动态显示静止状态，不运行摇摆、微光脉冲或光点漂移。访问记忆与旧回应序号保持，避免切换渲染器后重播旧回应；阅读面板期间环境回应暂停。

## 焦点检查及保留限制

修复地图关闭／跳转时在花园 surface 仍为 inert 的同一时刻尝试聚焦的问题：现在等下一帧恢复可交互后再将焦点交回花园。实际关闭 Map 后直接按方向键，角色从 `(1326.179641, 4133.934671)` 移到 `(1344.969411, 4166.263331)`；地图跳到石拱后直接按方向键，也从 `(-1020, 5260)` 移到 `(-1038.317206, 5202.992588)`。这两次是独立的地图焦点检查，不作为前述自然行走证据。

顶部音乐快捷入口仍有一项限制：关闭音乐面板后焦点恢复到该快捷按钮，此时直接按方向键不行走。证据 `arrow-keys-on-header-focus-do-not-walk` 保留了这个实际结果。本次返程先点击石拱的 Stir the chime，将焦点交回花园，再实际按方向键走回蘑菇空地。因此，面板位置恢复通过不等于所有面板关闭路径都支持立即用方向键继续行走。

## 减少动态与图片加载失败

正常素材下，在蘑菇空地与石拱分别切换减少动态，再恢复 WebGL。两组切换前后七项角色／镜头值完全相同，`worldEvents` 集合不变；没有因为切换新增访问事件。静态画面保持物件的世界位置、大小、落脚点和邻近植物关系，背景纹理有简化，不声称逐像素相同。

另开 `/?qa=asset-error#music` 故意让素材请求失败，关闭音乐面板后使用方向键实际行走到两区。蘑菇和石拱均显示程序绘制替代，页面没有停在加载状态；每区又实际切换减少动态，替代物件布局和七项角色／镜头值保持。证据见 [fallback-evidence.json](qa/hollow-arch-20261102/fallback-evidence.json)，截图为 09–12。这是故意 404 的资源故障测试，不是实际断网或 GPU 故障测试。正常预览的浏览器日志为 0 error、0 warn；故障测试不能套用该结论。
