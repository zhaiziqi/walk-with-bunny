## 美术与交互观察

- 浓密、圆润的苔藓草丘构成鲜明的前后层次，溪流或小径连接各处。
- 粉色、奶油白花朵与手写标签提供轻柔、私人的气息。
- 独立灯具和物件承担导航入口，场景本身带出探索方向。
- 靠近后可进入粉色布帘等章节场景，阅读和互动形成独立停留空间。

本项目 M1 选择浅蓝天空、明亮苔藓草丘与手作微缩花园，遵循已确定的 A「走进秘密花园」方案。参考用于决定空间层次、配色和触碰节奏，不复刻角色、名字、城市记忆、私人通知或其他个人内容。
