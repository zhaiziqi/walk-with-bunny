# 八区域花园 · 实际检查记录

日期：2026-11-01。范围为桌面 M1 美术与探索交互；预览 `http://localhost:5173/`。本报告记录本轮实际执行，不以历史截图替代新版本检查。

## 本轮结果

- 八个固定区域、十二条连接路径、五个独立环路。七条主路合计约17,056世界单位，以240单位/秒匀速计算约71秒；这是几何长度估算，不包含转弯、停留和支路，也不是声称已连续走完全部路线。
- 地形上的道路改为连续纹理绘制，修复山坡遮挡造成的路面碎片；地面固定在景物前绘制，修复深处地形错误盖住兔子的问题。
- 新增柳树、花树、蕨草与白铃花、旧石拱门四张原创透明水彩素材。树冠与枝叶同风摆动，根部固定；小兔有起步、小跳、身体形变、耳朵跟随、呼吸及短暂足迹。
- 六处环境互动支持靠近/停留触发和附近按钮或E键再次触发：果园落花、柳塘水纹、蘑菇回应、拱门风铃萤火、山丘纸鸟、月光波纹。当前均为视觉效果。
- 池塘地图落点位于前岸，持续行走受到椭圆岸线约束；贴着岸边可斜向滑行，松手停留，反向可离开。

## 实际浏览器操作

在本机内置浏览器实际检查1280×720与1920×1080。读取页面公开的`data-*`属性作为操作证据，没有注入角色坐标或修改游戏状态。[操作记录](qa/atlas-garden/browser-checks.json)保留角色、镜头、方向、区域与事件状态。

最终重载后入口使用WebGL，角色与镜头回到初始位置，发现记录为空；本次重载之后捕获的控制台警告和错误均为0，见[最终控制台记录](qa/atlas-garden/final-console.json)。临时视口尺寸已重置，交付标签页保留在入口。

1. 入口按住向左前行，从`(0,-220)`到`(-230.840511,75.293509)`；松手后再次读取，角色与镜头保持原位。继续拖动向右改变方向，再反向走回，均有双轴位移。
2. 使用真实地图按钮逐一到达八个区域，访问标记保留；地图即时到达不触发跨越途中所有地点的互动。
3. 花灯处打开面板并滚动阅读，角色停止；关闭后恢复角色`(-570,610)`、镜头`(-570,830)`、缩放1及原朝向。
4. 在果园、柳塘、蘑菇、拱门、山丘、月光空地实际触发六处按钮/E键，页面记录分别出现`orchard-petals`、`pond-lilies`、`mushroom-chime`、`arch-awake`、`paper-flock`、`moon-ring`。
5. 从山丘实际按住走到世界Y约7689，确认沿途地面、树木、小兔的遮挡关系及松手停止；并在拱门区域再次实际前行、停留。
6. 1920宽屏下，从月光区域打开音乐快捷入口，镜头转至果园，原兔子坐标仍为`(-120,8360)`；关闭后精确恢复。池塘处重复远程阅读并返回，也保持`(-1120,2880)`。
7. 池塘前岸按住向水内走，停止在`(-1116.616108,2915.772682)`；斜向沿岸移动至`(-817.633928,3069.510479)`，没有站进水中央。
8. 切换“减少动态”后仍保留世界位置。静态月光区域与音乐面板执行检查，浏览器返回恢复原位置；静态地面与道路已修复大块色面和弯道缺口，画面仍比WebGL简化。

静态音乐阅读的`fullPage:true`截图曾遗漏HTML图片合成层，但页面DOM尺寸和素材加载正常。已用原生截图和`fullPage:false`视口截图交叉核对，花朵及树木显示正确；最终静态截图采用视口方式，未把截图工具异常当作页面缺陷。

## 范围与限制

- 当前仍是M1。完整信号谜题、九首曲目与礼物解锁未接入；固定业务规则没有改变，环境发现不会完成业务进度。未加入音频，未部署。
- 地形为真实网格，树木与兔子为透明水彩平面。兔子使用正背两张姿态和程序形变，并非完整骨骼动画；地图有限，也没有全场景实体碰撞。
- 池塘限制针对每次移动的目的点，持续小步行走会沿岸滑动；极大的滚轮位移可以越到对岸，不是完整的路径碰撞求解。
- 减少动态使用静态投影近似，省略动态环境回应，并保留较简化的路径、地面与阴影。未进行真实WebGL设备丢失故障注入，切换静态模式不等于所有显卡降级测试。
- 本次到访和环境发现仅保留在当前浏览会话，刷新后不持久化；路由历史中的导航位置与这些记录是不同状态。
- 未进行手机适配、跨浏览器兼容、低性能电脑帧率或长时间内存压力测试。当前视觉仍需用户实际体验，不宣称已达到Wayfinder的完整制作规模。
- 本轮重新查看Wayfinder启动和初始场景，后续原站交互检查遇到浏览器超时，未将其完整流程标为已验证；参考素材与项目原创素材分开保存。
