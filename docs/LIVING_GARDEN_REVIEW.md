# 灵动与探索感 · 实现前复核

日期：2026-10-30（Asia/Shanghai）。这是设计与回归检查清单，不是已执行测试或用户视觉验收。当前范围为电脑网页，原有谜题、音乐和礼物规则保持不变。

## 旧版问题的可观察依据

查看旧版 `qa/wayfinder-desktop/03-discovery.png`：全屏草地的细节尺度与明度近似一致；树、花灯和兔子主要以平面插画叠放；兔子与镜头的相对位置固定。页面具备移动输入与邻近反应，但尚不足以形成走进一个空间的体验。

已存参考研究能够支持的借鉴点是「行进 → 发现 → 环境回应」。Wayfinder 的完整成诗流程和声音此前未实测；Bellwoods 的完整场景与声音也未核验。此次不应以“完整复现”描述实现结果。

## 建议的空间节奏

| 区段 | 主角与可观察变化 | 留白与神秘感 |
| --- | --- | --- |
| 入口 `(0,-220)` 附近 | 保留获认可的水彩邀请；进入后兔子先迈步，镜头稍后跟随 | 一条细路、两侧不对称树影；只给一个方向暗示 |
| 约 `y=350–620` 的途中 | 草丛受经过影响；少量蝶从地面附近飞起并沿短段引路 | 让树干或缓坡暂时挡住花灯，避免一进入就看到所有目的地 |
| 花灯 `(-650,750)` | 逐渐走出遮挡，灯由暗转明；停留可观察局部回应 | 花灯是当前唯一清晰主角，后续花圃只作为朦胧色块 |
| 粉花 `(550,1550)` | 新的色彩和局部响应，路径可回走 | 不同时展开花灯、门和三个标签 |
| 小门 `(-250,2350)` | 远处先见轮廓或微光，靠近后见门与门槛 | 不自动打开礼物内容，不以计数器或任务列表驱动探索 |

这些坐标是本轮讨论的布景目标；验收必须按最终注册的世界坐标执行，不将本表当成最终代码事实。

## 关键实现约束

- 角色位置独立于镜头位置。方向依据兔子实际投影后的脚点计算；不能仍以屏幕中心或旧的固定脚点作为输入原点。
- 角色起步与转向可以平滑，但松手后角色与镜头应同时停止位移。停留时允许微小呼吸或耳朵动作，不继续“追赶”镜头目标。
- 透视地面、物件脚点、点击区、静态降级和阅读聚焦必须共用投影；物件依远近改变尺寸与空气色，根部落在同一地形高度函数上。
- 植物晃动从根部旋转；角色跳动与地面接触阴影分离。前后遮挡发生在世界空间，不用固定屏幕层假扮深度。
- 蝴蝶、草叶和水纹等回应与地点有关。不要围着鼠标永久飞行，也不要用满屏光点替代探索。
- 阅读时冻结行走及明显环境响应，计时暂停；恢复后不可因墙钟时间跳过整个动画。
- 关闭内容应还原独立的角色位置、镜头位置和缩放；浏览器后退/前进同样保留两份位置。
- 发现状态只影响氛围，不写入谜题、歌曲或礼物业务完成状态。

## 本轮验收矩阵

| 检查 | 真实操作与证据 | 通过条件 |
| --- | --- | --- |
| 起步与镜头跟随 | 在入口按住斜上方；记录连续的角色与镜头坐标 | 两轴均变化；开始时角色先移动，镜头跟随而非两者刚性绑定 |
| 松手停留 | 抬起后间隔观察坐标；同时看兔子脚部 | 两个位置与缩放保持不变，兔子没有滑行 |
| 转向与反向 | 持续按住并移向另一侧，然后松手再反向 | 能连续弧线转向，反向无需退回被截掉的拖拽距离 |
| 地面透视 | 同一地标远、中、近三次截图 | 地标大小与遮挡连续变化，远处低对比；不是整张壁纸等比缩放 |
| 第一段自然探索 | 从入口走到途中，再走到花灯；不用“去哪里”跳转 | 至少一次经过引起的环境变化，且花灯由遮挡或雾里逐步显露 |
| 因果回应 | 经过草丛、接近蝶栖点/水边，再离开返回 | 靠近才触发、位置固定，返回可辨认同一处；无鼠标尾迹替代 |
| 草地落地 | 穿过有坡度和树影的区域 | 兔脚、物件根部、阴影随同一地形；不穿到地板下或漂起 |
| 点击与拖动 | 从物件上开始长拖，再做一次短点击 | 长拖只移动，短点击开内容；命中区和可见物件一致 |
| 阅读与恢复 | 在移动后的斜向位置开花灯，按住背景/滚轮，关闭 | 阅读稳定；关闭恢复角色、镜头和缩放的完整前态 |
| 历史导航 | 关闭后浏览器后退、前进 | 内容/探索状态与角色、镜头一致，不瞬移到旧相对脚点 |
| 边界与宽屏 | 1440×900、1920×1080，走至各边再反向 | 无露底、无不可达物件、无卡住；最终景物不会被错误永久裁掉 |
| 静态降级 | 减少动态及 `?static` 路径 | 相同地点、投影和命中区；角色仍可走；停止动态不回到旧平面世界 |
| 会话状态 | 返回入口并重新进入/刷新 | 发现状态按明确策略重置；不写业务进度，计时无残留 |
| 控制台与构建 | 新会话控制台、类型检查、生产构建 | 无新增运行异常，相关检查通过；未执行项目如实记录 |

最终需保存本次实现的入口、途中、花灯实际截图；旧版图或参考站图不能作为本轮成功证据。若动画是本轮主要差异，除了静态截图，优先保留一次连续操作记录或能够复核的多个实时状态。
